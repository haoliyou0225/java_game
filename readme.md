config 配置包
专门放全局静态常量、游戏固定参数配置类，比如窗口宽高、钩子摇摆速度、不同矿石的分值重量、倒计时总时长这些不会在游戏运行中动态修改的固定数值，统一管理不用散落在各个业务代码里，后续调参改数值只需要改这一个包里的文件。

controller 控制层包
放所有业务调度核心代码，对应你们分工里人员2的钩子物理模块、人员4的GameManager游戏管理器模块，所有游戏主循环、输入事件分发、钩子运动逻辑、碰撞检测、对局流程调度的核心业务代码都收敛在这里，是整个游戏的逻辑中枢。

model 实体数据层包
放所有纯数据实体类，对应人员3的物品模型模块，比如玩家、矿石、钻石、炸药、坐标点这些只存属性、不包含复杂业务逻辑的实体类，所有数据定义统一放在这里，其他模块直接读取使用即可。

util 工具类包
放全项目通用的静态工具方法，比如物理计算工具、碰撞判定工具、随机数生成工具，所有模块都可以直接调用，不用重复写相同的工具逻辑。

view 视图层包
放所有UI渲染相关代码，对应人员1的UI层主开发模块，比如主菜单、游戏画布渲染、HUD分数面板、结算弹窗所有和画面绘制相关的代码，完全和业务逻辑解耦，后续改UI样式不用动核心物理逻辑。
